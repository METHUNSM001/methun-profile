# Methun Portfolio

## Run the project

1. Install Node.js.
2. Open this folder in VS Code.
3. Open the terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite.

## Customize

- Main image: `public/images/methun.png`
- Main app: `src/App.jsx`
- Styling: `src/App.css`
- Components: `src/components/`
- Replace project data in `Projects.jsx`.
- Replace certificate data in `Certificates.jsx`.
- Replace social links in `Contact.jsx`.

The portfolio includes:
- React + Vite
- Three.js particle background
- Framer Motion animations
- Responsive navbar
- Voice welcome using browser Speech Synthesis
- Home, About, Skills, Projects, Certificates, Experience and Contact sections
